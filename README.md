# AR Assignment 3

EN.601.654 / EN.601.454 — Introduction to Augmented Reality

## Files

- `Q2/`: WebXR Duck placement and manipulation.
- `Q3/e/`: camera-to-pixel projection in Python.
- `Q4/`: Phong reflection, parameter experiments, and two point lights.

## Run Q2

Serve the project root with Servez and open `/Q2/f/index.html` at the displayed server address. Internet access is required for external libraries. Controls and test status are in `Q2/README.md`.

## Run Q3(e)

From the project root: `python Q3/e/projection.py`. Parameters and tests: `Q3/e/README.md`.

## Run Q4

Open `/Q4/index.html` on the project-root server. Source files, parameters, and screenshot requirements: `Q4/README.md`.

## Model

Duck from Khronos glTF Sample Assets, with a solid-yellow material. Attribution and license: `Q2/a/assets/MODEL_CREDIT.md`.
